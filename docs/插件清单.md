## 为什么只入库两个

市场插件是原版安装、我们不改，重装时按上面的版本装回来即可。真正需要版本管理的是**自己写的和改过的**：

- `astrbot_plugin_fish_memory`：五层记忆 + 注入编排 + worker，全是自研
- `astrbot_plugin_qzone`：上游 v3.1.3，本地已打补丁（读说说卡片开关、posts.tid 去重、无权限跳过、说说节流、定时重复发修复等）

## 重装市场插件的注意

- `astrbot_plugin_qq_voice` 需要 `requirements.txt` 里的 `edge_tts`，否则语音发不出去
- 升级 AstrBot / 重装 venv 会覆盖 `site-packages` 里的 6.5 provider 补丁，升级后要重打 `patch_imgfix.py` + `patch_imgfix2.py`
- 三个孤儿配置（`angel_memory` / `stealer` / `meme_manager`）对应插件已不在，配置留着无害
