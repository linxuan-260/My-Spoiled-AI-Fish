# 依赖清单

这是一份**已验证可运行**的版本矩阵，来自实际运行的服务器。照这个装能少踩坑。

## 运行时

| 组件 | 版本 | 说明 |
|---|---|---|
| AstrBot | **4.29.3** | `pip show AstrBot` 可查 |
| Python | **3.12.16** | 装在 venv 里，入口 `$APP_DIR/.venv/bin/astrbot` |
| 操作系统 | Linux + systemd | 面板和 worker 都靠 systemd 托管 |
| OneBot 后端 | v11 | NapCat / SnowLuma 等均可 |

AstrBot 4.20+ 理论上可用，但本项目只在 4.29.3 上做过完整验证。

## Python 包

**五层记忆插件不需要任何第三方包**，只用标准库 + AstrBot 自带能力。

`QQ空间` 插件需要三个，其余都是 AstrBot 已经带好的：

| 包 | 本机版本 | 来源 |
|---|---|---|
| `Pillow` | 13.0.0 | qzone 显式依赖 |
| `json5` | 0.17.3 | qzone 显式依赖 |
| `apilmoji[tqdm]` | 0.3.1 | qzone 显式依赖 |
| `aiosqlite` | 0.22.1 | 随 AstrBot |
| `beautifulsoup4` | 4.15.0 | 随 AstrBot |
| `aiofiles` | 25.1.0 | 随 AstrBot |
| `aiohttp` | 3.14.5 | 随 AstrBot |
| `httpx` | 0.28.1 | 随 AstrBot |
| `pydantic` | 2.14.1 | 随 AstrBot |
| `apscheduler` | 3.11.3 | 随 AstrBot |
| `PyYAML` | 6.0.3 | 随 AstrBot |

安装：

```bash
$APP_DIR/.venv/bin/pip install -r deploy/requirements.txt
```

## 可选补丁

| 文件 | 什么时候需要 |
|---|---|
| `deploy/patches/patch_imgfix.py` | 用**智谱**多模态模型且报 400「image format/parse error」时 |

会改 AstrBot 的 `site-packages`（先自动备份）。**升级 AstrBot 后需要重跑**。

## 资源占用参考

线上实例（阿里云 4 GB）：

| 项 | 数值 |
|---|---|
| 磁盘 | 40 G，已用 15 G |
| 内存可用 | ~1.4 GB |
| 记忆条数 | 239（一个多月的量） |
| 注入账本 | 2405 条 |

内存吃紧时优先调小 `L3_life.tick_seconds` 的频次，而不是直接关 worker。
