# 配置

配置文件：`/opt/astrbot/data/config/astrbot_plugin_fish_memory_config.json`
（qzone 的配置在同一目录的 `astrbot_plugin_qzone_config.json`）

**改完立刻生效**，不用重启 —— 插件盯文件的 mtime，下次请求重新加载。

## master

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `shadow_mode` | `false` | 只记账不注入，用于排查 |
| `enabled_scopes` | `[]` | 空=全开；填了就只在这些会话生效 |
| `owner_id` | `""` | **必填**，主人 QQ。跨会话记忆靠它 |
| `public_scopes` | `[]` | 共享层来源会话 |
| `public_readers` | `[]` | 共享层读者，空=所有会话可读 |
| `budget_chars` / `budgets` | 见下 | 注入预算 |

### 预算

```json
"budgets": { "memory": 138, "mood": 72, "life": 60, "style": 130, "total": 400 }
```

- 单层超预算：整块丢弃（会打日志）
- 总量超预算：按 style → life → mood → memory 丢，保记忆
- `life` 默认 60 偏紧，实际使用中调到 **110** 更稳（生活块 89 字在 60 预算下会被静默丢弃）

## L1_memory

| 键 | 默认 | 说明 |
|---|---|---|
| `k` | `3` | 每轮注入几条记忆 |
| `min_score` | `0.12` | 低于此分不注入 |
| `weights` | semantic .18 / keyword .46 / graph .11 / importance .14 / freshness .11 | 检索打分权重 |
| `freshness_halflife_days` | `30` | 新鲜度半衰期 |
| `sub.semantic` | `false` | 需要 bge-m3 onnx，没装会自动跳过 |

衰减半衰期按 kind 分：`episode` 14 天会衰减，`fact` / `skill` / `lesson` 不衰减（`0` = 关）。

## 人格校验

```json
"persona_guard": { "enabled": false, "sha256": "<基线哈希>", "check_every_min": 10, "auto_restore": false }
```

`sha256` 必须是**当前线上人格**的哈希，否则面板会一直亮「人格被改动了」的红灯。

```bash
# 算当前人格哈希
/opt/astrbot/.venv/bin/python -c "
import sqlite3, hashlib
c = sqlite3.connect('/opt/astrbot/data/data_v4.db')
p = c.execute(\"select system_prompt from personas where persona_id='1'\").fetchone()[0]
print(len(p), hashlib.sha256(p.encode()).hexdigest())"
```

把输出填进 `sha256`，重启面板即可。注意 `auto_restore=true` 会**真的用基线覆盖人格**，改人格前请确认基线是你想要的版本。

## qzone

| 键 | 默认 | 说明 |
|---|---|---|
| `trigger.read_prob` | `0.001` | 聊天时顺手读说说的概率，**要小** |
| `trigger.publish_cron` | `30 23 * * *` | 自动发说说基准时间 |
| `trigger.comment_cron` | `0 8 * * *` | 自动评论基准时间 |
| `trigger.publish_offset` / `comment_offset` | `600` | 基准时间前后随机浮动秒数 |
| `trigger.send_read_card` | `false` | 读说说是否把卡片发出来 |
| `trigger.like_when_comment` | `true` | 评论时自动点赞 |

发说说另有硬节流（写在 `service.py` 里，不是配置）：两条间隔 ≥ 3 小时、每天 ≤ 6 条。

## 热重载的边界

改了 **worker 代码** → 重启 `fishmem-workers`；改了 **注入 / 检索代码** → 重启 `astrbot`；只改配置 → 什么都不用重启。

## 一个小坑

这个项目取配置用的是 `dget()` / `on()` 两个辅助函数，**`dget()` 不接受 `default=` 参数**（标量请用 `on()`）。写错会直接抛 TypeError，而不是悄悄返回默认值。
